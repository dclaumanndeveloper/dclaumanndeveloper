## 🚀 Featured projects

### [PeopleBuy API 3.0](https://github.com/dclaumanndeveloper/PeopleBuyAPI3.0)

<a href="https://github.com/dclaumanndeveloper/PeopleBuyAPI3.0"><img src="images/project-peoplebuy.svg" alt="PeopleBuy API 3.0" width="100%" /></a>

REST API for a marketplace, covering users, offers, categories, reviews and nearby-offer search.

- **Stack:** C#, ASP.NET Core, Entity Framework Core, SQL Server.
- **Explore:** JWT authentication, Swagger documentation and geolocation with the Haversine formula.
- **Quality:** Tests for geolocation, CPF/CNPJ validation and password hashing.

[Code and setup guide](https://github.com/dclaumanndeveloper/PeopleBuyAPI3.0#readme)

### [Organizer](https://github.com/dclaumanndeveloper/Organizer)

<a href="https://github.com/dclaumanndeveloper/Organizer"><img src="images/project-organizer.svg" alt="Organizer" width="100%" /></a>

Desktop application that sorts files by extension, category or optional local AI suggestions.

- **Stack:** Python, Tkinter, optional Ollama integration.
- **Explore:** Preview before moving files, undo, duplicate detection and custom rules.
- **Quality:** Automated tests and CI across Linux, Windows and macOS.

[Code and setup guide](https://github.com/dclaumanndeveloper/Organizer#readme)

### [MLImoveis](https://github.com/dclaumanndeveloper/MLImoveis)

<a href="https://github.com/dclaumanndeveloper/MLImoveis"><img src="images/project-mlimoveis.svg" alt="MLImoveis" width="100%" /></a>

Educational machine learning application for estimating property prices in Maringá, Paraná.

- **Stack:** Python, scikit-learn, pandas, Streamlit and FastAPI.
- **Explore:** Model comparison with cross-validation, a web interface and a REST API.
- **Quality:** Automated tests, CI and training metrics.
- **Scope:** Uses synthetic data. Results demonstrate the ML pipeline and do not establish accuracy on real market prices.

[Code, setup and model limitations](https://github.com/dclaumanndeveloper/MLImoveis#readme)
